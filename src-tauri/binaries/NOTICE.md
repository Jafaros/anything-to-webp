# Bundled WebP encoder

This application redistributes the official Google/WebM cwebp 1.6.0 Windows x64
executable without modification. The original user-provided 1.3.2 executable has
not been modified.

- Official downloads: https://developers.google.com/speed/webp/download
- Archive: https://storage.googleapis.com/downloads.webmproject.org/releases/webp/libwebp-1.6.0-windows-x64.zip
- Executable SHA-256: `6A2F5CB5DCE71366353AB1D9CAF9C636E039F25703ACFCE1C148EED346F2F72A`
- License: see `COPYING` and `PATENTS` in this directory, from upstream tag v1.6.0.

This binary targets Windows x64. To support another operating system or
architecture, package its official compatible encoder and update the resource
path. No system installation or PATH changes are needed.
